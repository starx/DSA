# Binary tree


First under [tree structure](./tree.md). Then, binary tree is a tree structure that has the following:

- At most 2 children
- Each node hat at most 1 parents
- There is exactly one path from the root node to reach a node in the tree.

## Data structure

We need a structure that does the following.

- A node value
- A pointer to the left
- A pointer to the right

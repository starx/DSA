# Tree

Some common terms to be familiar with:

*Node:*
An individual element in a tree that holds a value and may reference other nodes.

*Edge:*
A connection between two nodes representing their relationship. In trees for example, edges are typically directed from parent to child.

*Tree:*
A structure that consists of nodes and edges, arranged hierarchically, with one root node, no cycles, and each node (except the root) having exactly one parent.

*Parent node:*
A node who has one or more child nodes.

*Child node:*
A node that has a parent.

*Root node:*
The very first item in the tree, one who does not have any parent.

*Leaf node:*
A node without any children.

*Sibling node:*
Nodes that share the same parent.

*Depth (of a node):*
The number of edges from the root node to that node.

*Height (of a node):*
The number of edges on the longest path from that node down to a leaf.

*Path (of a node):*
The nodes and edges that needs to be followed to reach a node.

*Height (of a tree):*
The height of the root node.

*Subtree:*
A tree formed by any node and all of its descendants.
